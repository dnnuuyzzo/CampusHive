## 💡 About CampusHive

**CampusHive** is a lightweight, modern web platform designed to solve fragmented campus communication, asking anxiety, and cross-major student collaboration hurdles. It unites peer-to-peer academic problem-solving with multidisciplinary student project recruitment under one verified campus environment.

---

## ✨ Key Features

- **Academic Q&A**: Filter course-specific questions, vote on helpful answers, paste syntax-highlighted code snippets, and accept solutions.
- **Pseudonymous Asking Mode**: Helps students ask questions without fear of judgment while keeping verified university credentials.
- **Project & Idea Hub**: Pitch capstone, competition (e.g., PIMNAS), or startup concepts and recruit teammates across engineering, business, and design.
- **Virtual Study Rooms**: Join focused, distraction-free study spaces with real-time peer discussion before exams.
- **Department Hall of Fame**: Earn peer karma reputation points and unlock academic achievement badges for helping classmates.

## 🚀 Getting Started

### 1. Clone repository
```bash
git clone https://github.com/dnnuuyzzo/CampusHive.git
cd CampusHive
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
